EMBERLINE — a round-based tactical FPS in three.js on the original Cinderworks map: two teams, bomb plant/defuse, a buy menu, and bots that flank, hold and react. Built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Click to play. WASD to move, mouse to look, click to fire, R to reload, Ctrl to crouch, Space to jump, B for the buy menu, G to throw a grenade, hold E at a site to plant the Spark charge.
